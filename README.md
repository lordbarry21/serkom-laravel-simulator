# Serkom Laravel Simulator

Interactive, browser-based coding simulator and educational workspace built with Next.js, Tailwind CSS, Monaco Editor, and Zustand.

## Features
- **3-Panel IDE Layout**: Instruction guide, VS Code-like Monaco editor, and virtual terminal / live interactive preview.
- **Progression Engine**: Step-by-step interactive validation guards.
- **Virtual Artisan Shell**: Realistic console simulation for Laravel commands.
- **Live Preview**: Interactive customer menu and admin monitoring dashboard.

## Getting Started

### Prerequisites
- Node.js 18+
- npm

### Installation
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore the simulator.
